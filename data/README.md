# Tyrian's data

The freeware Tyrian 2.1 data files, with lower-case names (OpenTyrian
opens those). The one checked is `tyrian1.lvl`: 538,262 bytes, MD5
`a1e73e0586ce715ab7daaedfe9b98595`.

Nothing to do by hand: when they are missing, `opentyrian/get_data.sh data`
(which the SD card build in m9b-system runs) downloads `tyrian21.zip` from
camanis.net and unpacks it here. To use a copy you already have, put its
files here first. The DOS programs and documents are left off the card.

The music is rendered from these files (`tools/make_music.sh`).
